QUICK START GUIDE
=====================================================

1. Install Python dependencies:
   pip install -r backend/requirements.txt

2. Add company PDFs:
   Place your PDF files in: backend/documents/

3. Ingest documents:
   python backend/ingest.py
   
   Expected output:
   [INFO] Found X PDF file(s) to ingest.
   [INFO] Loading embedding model...
   [INFO] Connecting to ChromaDB...
   [INFO] Ingesting: document.pdf
   All documents ingested successfully.
   Total chunks stored in ChromaDB: XXX

4. Start backend server:
   cd backend
   uvicorn main:app --reload --port 8000
   
   Expected output:
   [INFO] Starting FastAPI server...
   [INFO] Backend running on http://localhost:8000

5. Open frontend:
   Double-click: frontend/index.html
   
   Or open in browser:
   file:///c:/Users/Student/Desktop/swsai/sws-ai-rag-chatbot/frontend/index.html

6. Start chatting!
   Type questions about your company policies
   Bot answers based on ingested documents only

=====================================================
TROUBLESHOOTING
=====================================================

Issue: "No PDFs found"
Solution: Place PDFs in backend/documents/

Issue: "ChromaDB collection not found"
Solution: Run python backend/ingest.py first

Issue: "GEMINI_API_KEY not found"
Solution: Check backend/.env file exists

Issue: "Cannot connect to backend"
Solution: Make sure backend is running:
  uvicorn backend.main:app --reload --port 8000
